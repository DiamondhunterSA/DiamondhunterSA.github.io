## Source and writing

The editable Markdown, configuration, build tools, and source assets are included in [firelink-source.zip](firelink-source.zip). Extract the source, use Node.js 20 or newer, then run:

```sh
npm install
npm run build
npm run check
npm run serve
npm run export
```

The source README explains how to write entries. The exported files are in `.preview/publish/`; publish their contents to this repository root. The site uses independent static HTML pages for direct links and refreshes. GitHub Pages publishes from `main` → `/ (root)`.

The initial learning and exploration entries are explicitly labeled starter content. Replace them as you add your own writing.
